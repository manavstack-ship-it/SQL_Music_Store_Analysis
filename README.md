# SQL Project: Music Store Analysis

## Project Overview

This is a beginner-friendly SQL project where you will learn how to analyze a music store database.

The project uses SQL to explore music playlist data and answer business-related questions. By analyzing the data, you can help the music store understand its sales, customers, popular songs, artists, and overall business performance.

## Project Goals

- Understand how to work with a database.
- Learn basic and intermediate SQL queries.
- Analyze music store sales and customer data.
- Find popular songs, albums, and artists.
- Answer business questions using SQL.
- Improve your data analysis skills.

## Tools Used

The following tools are used in this project:

- **PostgreSQL:** Used to store and manage the database.
- **pgAdmin 4:** Used to write and execute SQL queries.

## Database Schema

The Music Store Database contains multiple tables connected to each other.

These tables store information about customers, employees, invoices, tracks, albums, artists, and playlists.

The database schema helps you understand how the tables are connected.

## How to Use This Project

1. Install PostgreSQL on your computer.
2. Install and open pgAdmin 4.
3. Download or clone this project repository.
4. Import the Music Store database into PostgreSQL.
5. Open the Query Tool in pgAdmin 4.
6. Write and execute SQL queries to analyze the data.
7. Explore the results and answer business questions.
